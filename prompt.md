O arquivo `roms.dat` é uma lista xml, com a lista de "roms" suportado pelo emulador "Final Burn Neo".

Crie um arquivo `parentroms.html` (página web com html, css e javascript vanilla). Que permita eu enviar um arquivo no formato do arquivo `roms.dat`.

Após o envio do arquivo `roms.dat`, o usuário deve receber uma lista constando os nomes das roms, a descrição, o ano, o fabricante. Somente das "parent roms".

"Parent roms" são as roms que não possuem o atributo `cloneof` ou `romof`.

Se necessário, pesquise na internet, o conceito de "parent rom" para o emulador "Final Burn Neo". Antes de fazer o código.
